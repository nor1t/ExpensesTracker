ExpensesTracker
Intelligent expense tracking application for managing personal finances. Supports multi-user ledgers, category insights, and monthly budgeting with visual breakdowns, helping users make new friends.

📖 Overview
ExpensesTracker is a mobile application built with React Native (Expo) designed to simplify personal finance management. It allows users to track expenses across multiple ledgers, visualize spending by category, and manage monthly budgets through an intuitive interface.

✨ Features
Multi-User Ledgers: Create and manage separate expense ledgers for different users or purposes.

Category Insights: View detailed breakdowns of spending by category.

Monthly Budgeting: Set and monitor budgets on a monthly basis.

Visual Breakdowns: Interactive charts and visuals to help you understand your spending habits.

Cross-Platform: Built with Expo, runs on both Android and iOS.

🚀 Getting Started
Prerequisites
Node.js (v14 or later)

npm or yarn

Expo Go app (for testing on a physical device)

Installation
Clone the repository

bash
git clone https://github.com/nor1t/ExpensesTracker.git
cd ExpensesTracker
Install dependencies

bash
npm install
Start the development server

bash
npx expo start
Run the app

Scan the QR code with the Expo Go app (Android) or the Camera app (iOS).

Or press a for Android emulator / i for iOS simulator.
